    Setting up Ollama

    1. Install Ollama from ollama.com/download.
    2. Pull a model, for example ollama pull llama3.2 or ollama pull qwen2.5:7b.
    3. Make sure the server is running: ollama serve. On Windows and macOS the desktop app does this for you.
    4. If the connection fails with a 403, allow browser extensions to reach Ollama: OLLAMA_ORIGINS=chrome-extension://* ollama serve.

    Keyboard

    • Alt+Shift+B — check the field you are in now
    • Alt+Enter — apply the suggestion on screen
    • Alt+↓ / Alt+↑ — move between suggestions
    • Esc — dismiss the card

    Shortcuts can be changed at chrome://extensions/shortcuts.

    Where your text goes

    • Checks are sent to the Ollama server at the address on the Model tab, and nowhere else.
    • A downloaded model runs on this machine. An Ollama Cloud model runs on Ollama’s servers, so your text is sent to them.
    • The only other request Blue Pencil makes is to ollama.com/api/tags, for the list of cloud models. Turn off Offer Ollama Cloud models and it is never fetched.
    • Password fields, payment fields and code editors are never read.
